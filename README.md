# Tercer Parcial - Laboratorio de Programación II

Integración del sitio completo `phpavanzado` correspondiente al curso de PHP y MySQL Avanzado.

## 🚀 Requisitos e Instalación

1. **Servidor local**: XAMPP o equivalente con PHP y MySQL (MariaDB).
2. **Ubicación**: Colocar el proyecto en la carpeta `htdocs` de XAMPP (ej. `C:/xampp/htdocs/phpavanzado/`).
3. **Base de Datos**:
   - Abrir phpMyAdmin (`http://localhost/phpmyadmin/`).
   - Importar el archivo `phpavanzado.sql` ubicado en la raíz para crear la base de datos `phpavanzado` y sus tablas (`clases`, `productos`, `registro`, `consultas`).
4. **Ejecución**: Ingresar desde el navegador a `http://localhost/phpavanzado/index.php`.

## 📁 Estructura del Proyecto

1. **Unidad 1**: ABM de clases (`unidad1.php`, `insertar_clases.php`, `ver_clases.php`).
2. **Unidad 2**: Cálculo de fechas (`unidad2.php`, `calculo_fecha.php`).
3. **Unidad 3**: Manejo de archivos de texto (`unidad3.php`, `comentarios.php`, `comentarios.txt`).
4. **Unidad 4**: Procesamiento de imágenes con GD (`unidad4.php`, marca de agua y miniatura).
5. **Unidad 5**: CAPTCHA y envío de consultas (`unidad5.php`, `cargar_consulta.php`)
6. **Unidad 6**: POO y Encapsulamiento (`unidad6.php`, `usuarios.php`, `caract_usuarios.php`).
7. **Unidad 7**: CRUD de productos con POO (`unidad7.php`, `clase_producto.php`).
8. **Unidad 8**: Registro y login de usuarios con hash de contraseña (`unidad8.php`, `cargarusuario.php`, `verificarusuario.php`).
